# Nibble-additive target harness

Identity: ASTRA. The four registered paired-key cases have completed and are independently verified. See [RESULTS.md](RESULTS.md) for the result, limits and reproduction commands.

The driver tests periods 19 and 57 with independent nibble subtraction and Beaufort after fixed equal-cut-4 ZOMBIES decode-forward. It records every key-residue mask and observed byte index/value. The gate pins the exact scope and ten dependency artifacts. Existing result/tmp files prevent a second target run; `--verify` rebuilds the input geometry independently and uses exhaustive slow masks.

`driver_controls.py` reads no Rev7 data. It reconstructs all six parent plants for hexadecimal periods 19, 38 and 57, restores their geometry by an index formula, compares the driver masks with slow masks and the frozen parent ledger, and verifies true-key retention.
