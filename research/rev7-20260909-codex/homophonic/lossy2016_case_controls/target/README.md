# Lossy AMSCO `2016` mixed-case target driver (inert)

This exact 16-context scope uses the accepted four-state word grammar over ASCII letters and SPACE: lowercase, Titlecase, or ALLCAPS words with arbitrary leading, repeated, and trailing spaces. It is distinct from the uppercase-only target. Cipher, IV, orientation, 819-byte natural length, `FF,0F,F0` mask, and caps remain unchanged.

Every complete solution is checked with independent PyCryptodome CFB8, exact legacy source emission, a separate regular expression, and a separately written DFA replay. Synthetic controls traverse every context with a mixed-style plant. A cap is incomplete, never a negative.

Default execution hashes sources only. A future immutable gate and explicit root GO are required.
